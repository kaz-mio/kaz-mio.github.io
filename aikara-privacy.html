アイカラ集計 プライバシーポリシー

制定日：2026年11月28日 ／ Effective: November 28, 2026
YouTube API サービスを使用しています ・ Uses YouTube API Services

1. このポリシーについて

このプライバシーポリシーは、KAZ & MIO（以下「運営者」）が YouTube チャンネル「アイカラスタジオ」の運営のために使用するツール「アイカラ集計」（以下「本ツール」）における、情報の取り扱いを説明するものです。サイト全体の取り扱いについてはサイトのプライバシーポリシーをご覧ください。

2. YouTube API サービスの使用

本ツールは YouTube API サービス（YouTube Data API v3 および YouTube Analytics API）を使用しています。本ツールの利用者は、YouTube 利用規約に同意したものとみなされます。

Google による情報の取り扱いについては、Google プライバシー ポリシーをご覧ください。

3. 取得する情報

本ツールは、利用者（チャンネル所有者本人）が Google アカウントでログインして許可した範囲で、次の情報を取得します。

  • チャンネルの基本情報（チャンネルID、登録者数、総視聴回数、動画数）
  • 自分のチャンネルの動画の情報（動画ID、タイトル、公開日時、長さ、公開状態）と統計（視聴回数、高評価数、コメント数）
  • YouTube アナリティクスの数値（視聴回数、高評価数、平均視聴時間、平均視聴割合、登録者増）
  • Google の認証で発行されるアクセストークン（ログイン状態を保つため）

本ツールは、他のユーザーの個人情報や、視聴者個人を特定できる情報は取得しません。

4. 利用目的

  • 自分たちのチャンネルの数字を記録し、動画ごとの成果をレポートにまとめるため
  • 自分たちの動画のアップロード、タイトル・説明欄の設定、再生リストへの追加、コメントの投稿を行うため

上記以外の目的には使用しません。広告配信やプロファイリングには使用しません。

5. 保存と共有

取得した情報は、運営者のパソコンの中にファイル（CSV）として保存します。外部のサーバーへの送信、第三者への提供・販売・共有は一切行いません。本ツールは Cookie や類似の技術を使用しません。

6. 保存期間と削除

  • 動画のタイトルなどの情報は、少なくとも30日ごとに YouTube から取得し直して更新するか、削除します。
  • 視聴回数などの統計情報は、運営のふり返りに必要な期間だけ保存し、不要になったものは削除します。
  • 利用者が本ツールへのアクセス許可を取り消した場合、保存しているアクセストークンと取得した情報は7日以内に削除します。

削除のご依頼は、お問い合わせページからご連絡ください。

7. アクセス許可の取り消し方法

本ツールへのアクセス許可は、Google アカウントの「サードパーティのアプリとサービス」の設定ページから、いつでも取り消すことができます。

8. 変更とお問い合わせ

このポリシーを変更した場合は、このページに最新の内容を掲載します。本ツールの情報の取り扱いに関するご質問は、お問い合わせページからご連絡ください。

Privacy Policy (English)

This Privacy Policy explains how KAZ & MIO ("we") handle information in "Aikara Shukei" ("the Tool"), an internal tool we use to operate our YouTube channel Aikara Studio.

YouTube API Services

The Tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). By using the Tool, users agree to be bound by the YouTube Terms of Service. Please also refer to the Google Privacy Policy.

Information we access

  • Basic channel information (channel ID, subscriber count, total views, video count)
  • Information and statistics of the channel's own videos (video ID, title, publish time, duration, privacy status, views, likes, comment counts)
  • YouTube Analytics metrics (views, likes, average view duration, average view percentage, subscribers gained)
  • OAuth access tokens issued by Google, to keep the user signed in

The Tool does not collect personal information about viewers or other users.

How we use it

Only to record and report our own channel's performance, and to upload, title, describe, add to playlists and comment on our own videos. We never use the data for advertising or profiling.

Storage and sharing

Data is stored only as files on the operator's own computer. We do not send it to external servers, and we do not share, sell or disclose it to any third party. The Tool does not use cookies or similar technologies.

Retention and deletion

Video metadata such as titles is refreshed from YouTube or deleted at least every 30 days. Statistics are kept only as long as needed for reviewing our channel and deleted when no longer needed. If a user revokes the Tool's access, stored tokens and data are deleted within 7 days. To request deletion, please use our contact page.

Revoking access

You can revoke the Tool's access at any time from the Google Account "Third-party apps & services" page.

Changes and contact

Any changes will be posted on this page. For questions, please use our contact page.
